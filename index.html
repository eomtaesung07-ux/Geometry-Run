🧩 맵 코드 공유 · 1.9

Firebase나 계정 없이 사용할 수 있어요. 편집한 맵을 코드로 바꿔 복사한 뒤 친구에게 보내면 됩니다. 받은 코드를 아래에 붙여넣으면 맵이 에디터로 들어와요.

1. 내 맵 코드 만들기

먼저 스테이지 에디터에서 맵을 만들고 저장해 주세요. 코드에는 맵 데이터가 들어가므로 맵이 복잡하면 코드가 길어질 수 있어요.

2. 코드 복사 / 받은 코드 붙여넣기

참고: 이 방식은 코드를 직접 전달하는 오프라인 공유예요. 짧은 코드 검색이나 공개 맵 목록은 아직 서버가 필요하므로, 나중에 온라인 서버를 연결할 수 있도록 코드 데이터 형식은 따로 유지합니다. 공식 스테이지는 덮어쓰지 않아요.
